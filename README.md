## Запуск приложения 
### На Linux

1. **Убедитесь что у вас установлены все необходимые зависимости:**
    + GCC/G++: версия 7.0+ (с поддержкой C++17)
    + SFML: 2.5.1 - 2.6.x
    + Утилита Make
2. **Клонируйте репозиторий:**  
   
   ```bash 
   git clone https://github.com/DerseTTing/CastOut-Engine.git
   ```
3. **Перейдите в папку репозитория:**
   ```bash 
   cd CastOut
   ```
4. **Запустите приложение через утилиту Make:**
   ```bash 
   make run
   ```
